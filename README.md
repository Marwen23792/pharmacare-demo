# PharmaCare — démo interactive

Maquette cliquable de PharmaCare, logiciel de gestion d'officine pour la Tunisie : caisse, stock par lot (FEFO), CNAM, ordonnancier, clôture Z.

**Données fictives.** Tout se passe dans le navigateur ; rien n'est enregistré et tout est réinitialisé au rechargement.

Démo en ligne : https://marwen23792.github.io/pharmacare-demo/
